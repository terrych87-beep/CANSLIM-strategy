`.../vISSUE_ShareBonus/stockid/{code}.phtml`（含除权除息日、送转、红利）。

基准指数 `sh000300` 日 K：**可拉**，供 L/M。

#### 7.2.1 自建前复权算法（Q2=B，已确认）

分红表字段（新浪「分红配送」已实施行）：除权除息日 `ex_date`、送股(股)/10 → `song`、转增(股)/10 → `zhuan`、现金红利(税前)/10 → `cash10`。

换算每股：

- `stk = (song + zhuan) / 10`（送转增加的股数比例）
- `cash = cash10 / 10`（每股现金红利）

对每个除权事件，取除权日前一交易日 **不复权** 收盘价 `P_pre`（因子计算不得读已复权序列）：

\[
factor = \frac{P_{pre} - cash}{P_{pre} \times (1 + stk)}
\]

（无送转无红利则跳过；`P_pre<=0` 或分母为 0 则该事件记警告并跳过。）

**前复权**（最新价不变）：按 `ex_date` **从新到旧**遍历事件，对所有 `date < ex_date` 的 OHLC 乘以该次 `factor`（累乘）。成交量首版**不复权**（S 用量比，对绝对量缩放不敏感）。  
截断窗口内：只处理 `first_date < ex_date ≤ last_date` 的事件。

边界：

- 配股：若分红表无可靠配股价/配股比，**首版忽略配股事件**并打日志（不猜）。
- 仅「实施」状态行参与；预案/不实施丢弃。
- 指数 `sh000300`：不做个股分红复权。

### 7.3 Q3 财务 C/A — **够用（同比需自算）**

- 接口：  
  `https://quotes.sina.cn/cn/api/openapi.php/CompanyFinanceService.getFinanceReport2022?paperCode={sh|sz}{code}&source=gjzb&type=0&page=1&num=12`
- 样本：`sh600519` / `sz000858` / `sh600000` 均 200，多期报告齐全。
- 关键字段：

| CANSLIM 需要 | 新浪字段 | 用法 |
|--------------|----------|------|
| C 扣非同比 | `扣非净利润`（绝对值，多期） | **同比自算**：本期 / 去年同期 − 1；阈值 ≥25% |
| A 净利同比 | `归属母公司净利润增长率`（已是同比%）或 `归母净利润` 自算 | 阈值 ≥25% |
| A ROE | `净资产收益率(ROE)` | 阈值 ≥15% |
| （辅助）营收 | `营业总收入` / `营业总收入增长率` | 可选，不作首版硬门槛 |

注意：

- **没有**现成「扣非同比%」字段，必须用两年同季度 `扣非净利润` 相除。  
- `归属母公司净利润增长率` 对 000858 与自算归母同比一致量级（如 20260930≈50%），可直接用；若缺则回退自算。  
- 值为报告期**累计**口径；同比必须用**同报告期类型**（Q3 对 Q3），禁止混用年报/季报。
