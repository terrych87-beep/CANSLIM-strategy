# 本地 data/ 辅助文件说明（不进 Git 的 CSV 除外）

本目录除行情 CSV、特征表外，以下文件**保留在本地**，供同步/聚宽导出/快捷启动使用。

| 文件 | 用途 |
|------|------|
| `指数数据.txt` | 聚宽导出的指数 K 线日志（合并 1m 等时的来源） |
| `期货数据.txt` | 聚宽导出的期货相关日志 |
| `运行实时数据.bat` | 从 `data/` 目录双击启动实时同步（等价于根目录 `启动实时数据同步.bat`） |
| `jq_1m_sparse.csv` | 聚宽 1m 稀疏补数中间产物（可选） |
| `大盘指数模板.xlsx` | BBD **历史参照**（校验用）；正式产物为根目录 `大盘资金流向.xlsx` |

**诊断输出**：`data/_*.txt` 为开发期一次性对比结果，已清理；再生时不提交。

**进 Git 的脚本**：`实时数据运行.py`、`期货合约数据获取.py`、`bar_filters.py`（见 `BASELINE_v3.1.md`）。

**scripts/ 索引**：见 [`../scripts/README.md`](../scripts/README.md)。
